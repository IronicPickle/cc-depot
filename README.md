# Computer Craft Depot

> What does this do?

CC Depot is an improved version of my old CC Store project, that comes with new and improved usability and functionality.

In short, it functions as a public repository for a variety of programs. It provides a convinient way to download programs and their dependancies in-game, straight to a computer. Upon installation, a runner handles program configuration, execition and general management, alongside updating.

To get started, simply run the following command in a computer in-game and follow the install process:
`pastebin run rRY4zxAx`
